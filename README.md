# claude-plugins

Personal Claude Code plugin marketplace.

## Plugins

| Plugin | Description |
|--------|-------------|
| [android-builder](plugins/android-builder/) | Build Kotlin/JVM and Android projects without a local SDK — runs entirely in Docker |
| [android-installer](plugins/android-installer/) | Install APKs on Android devices wirelessly — no USB, no local Android SDK, runs entirely in Docker |
| [readme-writer](plugins/readme-writer/) | Write user-focused README files tailored to how the project actually works |

## Installing

Add this marketplace to Claude Code:

```
/marketplace add <github-url>
```
